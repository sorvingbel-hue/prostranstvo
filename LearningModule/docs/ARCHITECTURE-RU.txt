СЛОИ И ЗАВИСИМОСТИ
Standalone UI ---- LearningClient ---+
                                    +--- LearningCore --- ContentPack
ProstranstvoAdapter - LearningClient +          |          ExactCheckers
                                               +--------- LocalRepository

LearningCore не импортирует WindowsCompanion, tkinter, Windows API,
Telegram, микрофон, браузерную историю или систему родительских ограничений.
Персонаж/озвучка/кнопки принадлежат клиенту. Учебное содержание принадлежит ядру.
Управление приложениями Windows принадлежит отдельному родительскому компоненту.

ПЕРВЫЙ ТРАНСПОРТ
Отдельный локальный процесс + ограниченный stdio JSON request/response.
Оба клиента используют один контракт. Локальный HTTP/MCP — будущие адаптеры,
не обязательная предпосылка первого прототипа. Открытого порта/облака сейчас нет.
Встроенный Python-вызов возможен в тестах; контракт не зависит от Python.

Проект команд: module.describe, task.create, session.start, turn.submit,
session.snapshot, session.stop, report.export. Идентификаторы задачи,
учебной сессии и сеанса Windows различаются. Имя ребёнка не ключ идентичности.
Для parent-only экспорта/настроек клиент обеспечивает явную авторизацию;
предоставленный ребёнком profile_id не является доказательством полномочий.

ПРОЕКТ КОНВЕРТА ЗАПРОСА V1
schema_version, request_id, operation, params;
для меняющих состояние команд — expected_revision.
Сначала ограничить размер строки/число полей/длину текста/время операции,
потом разбирать запрос. Не выполнять код, пути или URL из текста задания.
Повтор request_id с теми же параметрами возвращает исходный результат;
тот же ID с другими параметрами — конфликт. Проверять версию и ревизию.

ПРОЕКТ КОНВЕРТА ОТВЕТА V1
schema_version, module_version, request_id, status, session_revision,
result, evidence, limitations. Status: completed, needs_clarification,
unsupported, cancelled, conflict, unavailable, failed.
Ошибка не подставляет произвольный exception/путь/секрет в детскую реплику.
Частично полученный ответ не считается завершённым действием.

ВОЗМОЖНОСТИ И ДОКАЗАТЕЛЬСТВА
module.describe сообщает доступность процесса, версию контракта и список
возможностей с независимыми planned/implemented/verified.
Для verified указывать scope, метод, версию и ссылку на проверку.
Проверка формата данных не подтверждает работающий движок. Автотест дробей
не подтверждает эффективность обучения, произвольный OCR или реальный голос.
Манифест текущей концепции содержит только planned, runtime_available=false.

ЛОКАЛЬНОЕ ХРАНЕНИЕ
Будущая собственная SQLite: assignments, sessions, attempts, hints,
assessments, content_versions, processing_consents и export_receipts.
Транзакции для пары попытка→результат и таблица идемпотентности.
Персональные данные вне установленного программного каталога; назначенные
каталоги пользователя/семьи, ограниченные права, срок хранения и очистка.
SQLite/локальная папка сами по себе не обещают шифрование или изоляцию между
людьми в общей Windows-учётке. ACL и роли проверяются отдельно.
Чистый установщик содержит только вымышленные примеры, не журналы пилота.

ПАКЕТЫ СОДЕРЖАНИЯ
Версия, skill_id, применимый стандарт/класс, языки, объяснения/модели,
тип проверяющего, лицензии и provenance. Пакеты — данные, не исполняемые
скрипты из Интернета. Новые проверяющие идут с кодом/ревью/обновлением модуля.
Стандарты не копируются как готовый набор школьных учебников.

ВНЕШНЯЯ МОДЕЛЬ — ОТДЕЛЬНЫЙ БУДУЩИЙ АДАПТЕР
Должны быть выбраны провайдер/лицензия/возрастные условия/передаваемый контекст,
лимит расходов и согласия. Пока adapter отсутствует. Локальная база не делает
вызов внешнего AI локальным: документировать сеть и передачу конкретных данных.
Ответ модели считается предложением: проверка поддерживаемых вычислений
производится независимо. Текст задания/страницы — данные, не системные команды.

ИНТЕГРАЦИЯ С РОДИТЕЛЬСКИМ КОНТРОЛЕМ
Учебный модуль может получить read-only наблюдение таймера вместе с источником
и подтверждённостью. Он не владеет PIN, полномочиями SYSTEM или allowlist.
Запрос добавить учебный сайт — предложение для родительского компонента,
не автоматическое разрешение по ответу модели или содержимому страницы.
Ошибка/закрытие обучения сохраняет исходные правила Windows и доступ к родителю.

ТРЕБОВАНИЯ К ПОСТАВКЕ
Отдельная версия/сборка/проверка/удаление. Хост сверяет совместимость контракта
и умеет работать при отсутствии модуля. Откат не теряет историю.
Импорт личного профиля, автозапуск, микрофон, сеть и обновление действующего
котёнка не являются побочным действием установки учебного пакета.
