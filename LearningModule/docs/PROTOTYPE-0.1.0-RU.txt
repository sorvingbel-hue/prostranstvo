УЧЕБНЫЙ МОДУЛЬ 0.1.0: ЛОКАЛЬНЫЙ ПРОТОТИП

ЧТО РАБОТАЕТ
Самостоятельное окно RU/EN; четыре готовых задания и свои два числовых
операнда; сложение неотрицательных дробей меньше единицы, с суммой меньше2.
Целый ответ или дробь a/b, точная проверка значения и сокращения по условию.
Четыре уровня подсказок, ограниченная графическая модель и похожая задача.
У последнего уровня есть полный разбор; последующий успех отмечен как с помощью.
Ошибка записи/неподдерживаемый формат не считается математической ошибкой.
Локальная история, открытие занятия, остановка и экспорт фактической сводки.
Сеансы и попытки сохраняются в SQLite; повтор принятого запроса после
перезапуска возвращает прежний результат, без новой попытки.

Питомец может использовать отдельный адаптер dialogue.reply через локальный
клиент. Проверяется совместимость с текущим интерфейсом, но действующий
Мурчик этим релизом не переподключён. Сбой учебного модуля не меняет Windows.

КАК ЗАПУСТИТЬ
Полностью распаковать portable ZIP в отдельную папку и открыть LearningModule.exe.
Дополнительный Python на ПК получателя не требуется; поставка Windows x64.
При запуске из исходников: Python3.13 + Tk, run_learning.py.
Данные по умолчанию: %LOCALAPPDATA%\ProstranstvoLearning\learning.sqlite3.
Для отдельной папки: LearningModule.exe --data-dir "D:\MyLearningData".
Английский интерфейс: --language en; язык можно сменить и в окне.
Файл программы и папка истории различаются; обновление кода историю не заменяет.

Протокол интеграции: LearningModuleCore.exe --stdio --data-dir "папка".
UTF-8 JSON по одному запросу в строке, schema_version1.0, без сетевого порта.
Ограничения: запрос32КиБ, ответ64КиБ, IDдо64ASCIIбукв/цифр/_/-,
ревизия занятия обязательна для turn.submit/session.stop.
Документация операций: contracts/PROTOCOL-RU.txt.

ЧТО ЭТО НЕ ПОДТВЕРЖДАЕТ
Педагогическая эффективность с детьми не проверена. Верная арифметика не
доказывает понимание, свободное объяснение ребёнка или владение школьным курсом.
Самостоятельный успех означает ответ без подсказки внутри текущей задачи,
а не доказательство отсутствия помощи вне приложения или освоения навыка.
Детерминированные похожие примеры могут повторяться при многократной практике.
Обозначать их как постоянно новые или как стандартизированный тест нельзя.
Метод конкретного учителя неизвестен. Работает ограниченный проверяющий;
произвольный текст задания, фото, свободный AI-диалог и голос ещё не реализованы.
Нет школьной авторизации, базы школ, облачной базы или доступа к истории браузера.

ДАННЫЕ И ДОСТУП
История сохраняется локально. Отдельной родительской аутентификации здесь нет:
другой человек с этой Windows-учёткой может открыть историю/экспорт.
Экспорт явный, только в подпапку exports выбранной папки данных.
Экспорт включает все задания, к которым относятся события, а не только последнее.
Неизвестный результат записи требует повторить тот же запрос/обновить историю;
прототип не объявляет запись успешной после ошибки диска.
Исправленный пользователем экспорт автоматически не перезаписывается.
Лимиты: 1000 занятий, 200 событий на занятие, 20000 квитанций запросов;
при достижении лимита существующие данные сохраняются, новые действия отклоняются.
Окно показывает до100последнихзанятий; stdio-клиент дополнительно ограничен
размером ответа. Длительные реальные нагрузки остаются отдельной приёмкой.

ПОЛНОМОЧИЯ
Обычные пользовательские права, без службы/автозапуска/скрытия процессов.
Остановка занятия не снимает родительский таймер, программа не закрывает браузер.
Микрофон, камера и сеть учебному прототипу не нужны и им не включаются.

ПОСТАВКА
Это unsigned локальная beta. Сборка и проверки на этом ПК не заменяют
установку на второй чистой Windows, проверку с реальным ребёнком и юридическую
проверку перед коммерческим выпуском. Полная концепция остаётся в docs.
