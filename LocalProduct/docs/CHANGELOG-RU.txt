ПРОСТРАНСТВО LOCAL BETA — ИЗМЕНЕНИЯ

0.1.17 — родительское согласие и границы MCP
- Включение внешнего ИИ и открытие/сохранение его настроек требуют
  настроенного PIN родителя. Отмена, ошибка и неверный PIN не запускают
  сохранение; режим «Офлайн» остаётся доступным без PIN. PIN не передаётся
  рабочему потоку, модели или журналу. Это барьер UI общей учётной записи,
  а не защита от запуска собственного кода тем же пользователем Windows.
- MCP читает запрос ограниченным readline; слишком длинная строка
  завершает сеанс после одной ошибки, её остаток не исполняется.
- В отдельной личной WindowsCompanion-ветке SYSTEM MCP разрешает
  diagnostics/health/scan; repair/cleanup отклоняются до обращения
  к брокеру. Сам протокол службы и другие маршруты здесь не изменены.
  Portable-пакет по-прежнему не содержит эту личную SYSTEM-службу.
- Получено независимое ревью Claude: часть замечаний исправляется этим
  кандидатом, остальные системные/сетевые/производительные пункты
  требуют отдельной приёмки. Полный прогон исходников17:1101 тест,
  1096 успешных и5 пропусков,113.214 секунды, отдельный QA-desktop.
  Конкретный бинарный пакет проверяется отдельно; старый16 не доказывает17.

0.1.16 — исправление реальной межпроцессной гонки Windows
- Дополнительный запуск frozen worker0.1.15 выявил PermissionError при
  чтении служебного байта до получения файловой блокировки. Убрана
  ненужная инициализация содержимого lock-файла; timeout и guards сохранены.
- Добавлены реальные Windows-тесты: blocking ждёт освобождения, nonblocking
  возвращает busy, пустые и прежние однобайтовые файлы совместимы.
  Это тесты собственных дочерних процессов без окон и пользовательских данных.
- Полный прогон: 1083 теста, 1078 успешных и 5 пропусков; результаты
  настоящего пакета и домашней приёмки фиксируются отдельно.
- Сохраняется новый runtime из0.1.15; живая семейная и системная приёмка,
  реальные аккаунты и лицензионное покрытие остаются отдельными этапами.

0.1.15 — кандидат обновления runtime, приёмка ещё выполняется
- Подготовлена отдельная сборочная среда CPython 3.13.18 из проверенной
  Astral standalone-поставки; системный Python и личная D-среда не заменяются.
- Self-test сообщает фактические версии Python/OpenSSL/SQLite/zlib.
- Полный прогон исходников на новой среде: 1080 тестов, 1075 успешных,
  5 пропусков; учебная мастерская отдельно — 67 успешных.
- Сборка и повторная упаковка проверяют минимальный поддержанный
  runtime и совпадение версии приложения с исполняемым frozen Core.
- Полный набор внешних сценариев, происхождение и лицензии поставки
  оцениваются отдельно; новый runtime не является общим AI-щитом.

0.1.14 — кандидат после изолированных проверок
- Добавлены очищенный отчёт безопасности и отдельный stdio-канал только
  с двумя инструментами отчёта. Произвольные команды через него недоступны.
- Добавлен раздел объёма дисков: явный запуск анализа метаданных в фоне,
  прогресс и результат с отметкой неполного доступа. Удаления нет.
- После проверенного отката переноса квитанция не вызывает повторную
  ложную тревогу о необходимости ручного разбора.
- Проверены реальный frozen worker на собственных тестовых файлах,
  установка/обновление в отдельном профиле и ограниченный MCP-канал.
  Шесть семейных сценариев используют реальные хранилища и PIN на
  синтетических данных; настоящий Windows-контроль окон не задействован.
- Системные изменения, прошивка BIOS, живая слышимость, реальные
  аккаунты, перезагрузка и чистая VM этим выпуском не подтверждаются.

0.1.13 — предыдущий проверенный без GUI кандидат
- Сохранение блокировки попыток PIN между перезапусками; восстановление
  действующего занятия при повреждённых настройках и явный статус родителя.
- План дня открывается при старте/восстановлении занятия. Закрытие плана
  не завершает уроки. Одобрение относится к конкретному сеансу.
- Каталог известных приложений и отдельный headless-профиль браузера
  для агента. Существующие cookies не копируются; вход выполняет владелец.
  Node.js/Playwright для этой возможности устанавливаются отдельно.
- Родительские приложения могут работать свёрнутыми во время уроков;
  общий Windows-аккаунт не обеспечивает запрет доступа к ним.
- Вкладка питания: PIN, предупреждение, отсчёт и отмена до отправки
  штатной команды выключения или перезагрузки без принудительного /f.
- Диагностический отчёт для помощника, отдельная отметка непроверенных
  советов ИИ и анализатор объёма дисков без удаления личных файлов.
- SYSTEM-обслуживание личной установки в переносимый пакет не входит.
  Эта версия не является общим защитным щитом от атак других агентов.
- Сквозные проверки с настоящим входом в Windows, голосом, API и Telegram
  остаются отдельной приёмкой; сборка сама по себе их не подтверждает.

0.1.0
- Первый отдельный локальный пакет: установщик, portable, чистые исходники,
  встроенный Python и отдельная папка данных текущего пользователя.
- Необязательный stdio MCP, очередь и планы файлов, видимые семейные функции.
- Первоначально выключены запись, расписания, Telegram и автозапуск.

Ограничения: второй ПК/чистая Windows, реальные Telegram-доставки,
сон/автозапуск и нагрузка ещё требуют приёмки. Beta не подписана издателем.
Удаление через установщик сохраняет данные и код в резерве; сохраняйте
установщик именно своей сборки. Полный возврат любых изменений ПК не обещается.
