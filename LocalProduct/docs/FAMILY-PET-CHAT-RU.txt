ПРОСТРАНСТВО — СООБЩЕНИЕ ПАПЕ ИЗ ЧАТА ПЕРСОНАЖА

Встроенный персонаж ChatGPT/Codex открывает обычный чат помощника. Это
точка входа, а отправку выполняет отдельный локальный семейный инструмент.
Наличие персонажа не означает подключение Telegram. В этой beta поддержан
текст, намеренно выбранный для передачи; весь разговор не пересылается.

Эта инструкция относится к персонажу в ChatGPT/Codex и семейному MCP.
Отдельный настольный Мурчик отвечает локально по умолчанию; с 0.1.11
в нём есть необязательный OpenAI API. Он настраивается отдельно от Telegram
и MCP. Условия передачи контекста, ключа и ZDR описаны в CAT-AI-RU.txt.

ОДНОКРАТНАЯ НАСТРОЙКА
1. Подключить отдельного Telegram-бота в Пространстве -> Общение ->
   Настроить Telegram: токен вводится только в скрытое поле на ПК.
2. В личном Telegram открыть ссылку Start, подтвердить правильный аккаунт
   в приложении, включить доставку. Токен в чат с ИИ не присылать.
3. Для чистой установленной beta добавить отдельный семейный MCP:

   $familyBridge = Join-Path $env:LOCALAPPDATA 'Programs\ProstranstvoLocalBeta\app\ProstranstvoCore.exe'
   codex mcp add prostranstvo-family -- $familyBridge family-mcp

   Для portable подставить полный путь к Core в своей папке.
   Обновить MCP-соединения или открыть новую локальную сессию клиента.
   Настройка Codex на ПК сама по себе не подключает сервер к ChatGPT web.
   Не заменять config.toml целиком и не копировать чужие настройки/ключи.

ИСПОЛЬЗОВАНИЕ
В чат под персонажем написать: «Отправь папе: Я закончил уроки».
Помощник должен проверить family_channel_status и вызвать send_family_message
только с этим текстом и новым устойчивым request_id. При повторе ровно той же
отправки сохраняет request_id; новую отправку с новым ID не создавать,
если неизвестен результат предыдущей. Квитанция проверяется отдельной
family_message_status(message_id), без чтения всей переписки.

Если канал не подключён или приостановлен, инструмент возвращает отказ.
Если ответ queued — текст принят локальной очередью, доставка не подтверждена.
Если sent/accepted_by_telegram=true — Telegram принял сообщение. Это ещё
не доказывает появление уведомления на телефоне или прочтение родителем.
При uncertain не повторять автоматически: проверить Telegram и квитанцию.

Первую реальную проверку делают намеренно в обе стороны после привязки.
Ответ папы в бот сейчас показывается окном Пространства на компьютере.
В разговор персонажа входящие ответы автоматически не вставляются.
Клиент может потребовать подтверждение использования инструмента по своей
политике; подключение MCP не обходит правила клиента и Windows.

ГРАНИЦЫ
Семейный MCP предоставляет только три инструмента: family_channel_status,
send_family_message и family_message_status. Он не принимает произвольный
chat_id/получателя, не меняет токен/настройки, не читает другие чаты/файлы.
Другие инструменты самого ИИ-клиента управляются отдельно. Общая учётная
запись Windows не позволяет достоверно определить, кто именно печатает.
Отправка через чат ChatGPT/Codex требует работы этого ИИ-клиента; локальная
доставка очереди и зелёная кнопка настольного Мурчика модель не вызывают.
Интернет и включённый компьютер нужны для Telegram. Внешние ответы котика
включаются независимо и по умолчанию выключены; см. CAT-AI-RU.txt.
