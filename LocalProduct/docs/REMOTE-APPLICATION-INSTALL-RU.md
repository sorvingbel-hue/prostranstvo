# Удалённая установка программ и подключение веб-приложений

Требование владельца от 19 ноября 2026 года: **обязательно реализовать в будущем**.
Идентификатор: `APP-INSTALL-REMOTE-01`.
Статус: утверждённая цель; поиск, скачивание, установка и телефонный сценарий
ещё не реализованы. Этот документ не запускает установщики и не включает доступ.

## Что должен получить владелец

С телефона дать понятную команду: «Найди и установи программу на домашний ПК»
или «Открой Orcatec и подготовь его для работы помощника». Программа выполняет
поддержанные шаги на нужном компьютере и возвращает на телефон проверяемый
результат. Доступны Microsoft Store и официальные дистрибутивы разработчиков.
Приложения устанавливаются на ПК, а не на телефон.

Установка приложения, вход в аккаунт и разрешение агенту работать в нём —
три самостоятельных результата. Ни один не следует автоматически из другого.

## Сценарий с телефона

1. Выбрать привязанный компьютер и приложение. Запрос владельца считается
   намерением установить именно выбранную программу; повторные разрешения
   на каждый технический шаг не нужны. Неоднозначное название сначала уточняется.
2. Получить короткий план: точный package/product ID, издатель, официальный
   источник, версия, архитектура, пользовательская/общая установка, оценка
   места, стоимость/лицензионные условия, необходимость окна, UAC или перезапуска.
   Материально изменившийся план требует нового решения владельца.
3. Выполнить ограниченное задание: найти → скачать → проверить → установить →
   проверить установленную версию → при необходимости открыть.
4. Вернуть статус и квитанцию. Успех означает проверенную регистрацию/версию
   и поддержанную проверку запуска, а не просто exit code или открывшееся окно.
5. Для веб-сервиса отдельно пройти обычный вход владельца и подтвердить нужную
   учётную запись и доступное агенту действие. Затем работать в согласованных
   пределах: чтение данных, изменения, сообщения и финансовые действия различаются.

## Источники и исполнение

- Первый адаптер — штатный WinGet: точный ID и явный источник `msstore` либо
  проверенный пакет с официальным URL издателя. Общий каталог WinGet содержит
  community manifests и не равен Microsoft Store; происхождение показывается явно.
- Для официального сайта — отдельный ограниченный адаптер загрузки: HTTPS,
  проверенная связь домена с издателем, контроль перенаправлений и размера,
  подпись/хеш по доступному доверенному источнику, штатная проверка защиты Windows.
  Хеш, рассчитанный только из скачанного файла, не доказывает подлинность издателя.
- Не исполнять команды со страницы, рекламные кнопки, скрипты установки из чата
  или произвольный shell/installer arguments от модели. Не отключать проверку
  хеша, антивирус, SmartScreen или политики исполнения ради установки.
- Начать с поддержанных бесплатных пользовательских установок и малого набора
  проверенных приложений. Платная покупка, подписка и расширение прав являются
  отдельными действиями владельца; соглашения не принимаются незаметно.
- Перезапуск Windows не выполняется автоматически. Не закрывать работающие
  программы и не отбирать экран у ребёнка: фоновая установка только там, где её
  поддерживает издатель; иначе состояние «нужно окно для установки».
- Текущий SYSTEM broker имеет фиксированный список обслуживания и не умеет
  устанавливать программы. Будущий installer broker, если потребуется, получает
  отдельный узкий контракт и проверку безопасности, а не произвольное выполнение
  от SYSTEM. Первичная настройка прав может потребовать UAC на самом ПК.
- Нельзя обещать установку любой Windows-программы полностью с телефона:
  UAC, экран установщика, Store-аккаунт, лицензия или политика организации могут
  требовать участия владельца. Показывать точную причину ожидания без обхода защиты.

## Orcatec — первый целевой веб-сценарий

Официальная инструкция Orcatec указывает работу через Chrome на компьютере,
а также приложения для iOS/Android. Адрес веб-входа: https://app.orcatec.com/.
Это подтверждает браузерный путь; отдельный Windows-пакет Orcatec в Microsoft
Store этим исследованием не найден и не подтверждён.

Поэтому запрос «поставь Orcatec» сначала предлагает поддержанный веб-вариант:
подготовить нужный браузер/выделенный профиль, открыть официальный сайт,
при необходимости создать ярлык. PWA — только если сайт и браузер это поддерживают.
Если понадобится настоящая Windows-версия, её наличие проверяется отдельно.

Вход — штатный, с пользовательским вводом и 2FA при необходимости. Пароли не
передаются в чат или модель; cookies и профиль другого браузера не копируются.
Для полностью телефонного сценария нужен поддержанный защищённый handoff
пользовательского ввода. Если он недоступен, честно показывать «ожидается вход».
Наличие входа на телефоне не означает вход в отдельном браузере на ПК.

Агент получает ограниченный доступ к выбранному профилю и разрешённым доменам.
Проверяются нужный аккаунт/организация и чтение разрешённой страницы без изменений.
Нельзя считать «браузер запущен» доказательством авторизации или работой всех
функций сервиса. Существующие headless allowlists/ручной Facebook login не
дают доступ к Orcatec автоматически; требуется отдельное расширение и приёмка.

## Связь и надёжность

Переиспользовать имеющиеся очереди, квитанции, каталог приложений и browser
session; не строить новый универсальный удалённый shell. Телефонный транспорт
отделён от локального исполнителя. Telegram может стать первым пультом, но
нынешняя семейная очередь сообщений ещё не является каналом установки.

Команды принимает только привязанный владелец/родитель с правом установки.
Идентификация включает компьютер, роль, request ID, срок действия и точный план;
текст ребёнка, сайта или другого агента не является разрешением владельца.
Разрешение можно отозвать, задания и результат видны в интерфейсе.

Состояния: подготовлено / ожидает решения / в очереди / скачивается /
проверяется / устанавливается / ожидает UAC или входа / нужна перезагрузка /
установлено и проверено / ошибка / результат неизвестен / отменено.
После потери связи, сна или сбоя не запускать вторую установку автоматически.
Сначала сверить журнал и реальное состояние; неоднозначный исход не объявлять
ни успехом, ни разрешением повторить действие. Универсальный откат установки
не обещается: сохранность данных и доступный uninstall проверяются отдельно.

## Этапы будущей реализации и приёмка

1. Только поиск/карточка источника и read-only проверка доступных Store/WinGet;
   тестирование без запуска установщиков.
2. Один проверенный бесплатный пользовательский пакет: план, ограниченная
   установка, квитанция, отмена до запуска, проверка версии и повторного запроса.
3. Привязанный телефон: команда, прогресс, отключение связи, повтор доставки,
   запрет команды ребёнка и отозванного владельца; компьютер недоступен/выключен.
4. Веб-сценарий Orcatec: обычный вход владельца, правильная организация,
   разрешённое чтение агентом и сохранение профиля; без клиентских изменений
   и финансовых действий ради теста.
5. Затем расширять набор приложений и поддержанные machine-wide установки.

Проверить: неверный издатель/ID, подмена URL/подписи/хеша, недостаток места,
несовместимая архитектура, уже установленная версия, запрос покупки/UAC,
перезапуск, прерывание, изменение плана и отсутствие повторного запуска.
«Все действия с телефона без посещения ПК» считается пройденным только на
конкретном поддержанном сценарии; ограничения каждого пакета показываются явно.
