# Управление экраном через ИИ — 0.1.21

Отдельный локальный stdio MCP даёт подключённому ИИ снимок экрана, перемещение
мыши, одинарный/двойной щелчок, перетаскивание, прокрутку, Unicode-текст,
сочетания клавиш и управление обычными окнами. В приложении есть вкладка
«Доступ ИИ» с конфигурацией и настоящим общим STOP-маркером.

## Подключение

В установленной исходной версии используются `desktop_control_mcp.py` и
приватный Python приложения. В упакованной бете — `ProstranstvoCore.exe desktop-mcp`.
Строка запуска с `--enable-input --session-seconds 3600 --stop-file <абсолютный STOP>`
разрешает ввод на один сеанс до 60 минут. Без `--enable-input` доступны только
наблюдение и статус. Подключение stdio выполняет MCP-клиент (например Codex),
показ конфигурации в окне приложения не создаёт соединение.

При вводе обязательно видимое окно «СТОП». Нажатие STOP в этом окне, инструмент
`desktop_stop`, общий STOP-файл или истечение времени отзывают ввод и новые
снимки. Удаление STOP-файла после подтверждения родителем разрешает только
будущий новый процесс. Остановленный процесс сам не возобновляется.

Каждое действие использует свежее одноразовое наблюдение: проверяются сеанс
Windows, рабочий стол, фокус, процесс и координаты. Нельзя повторять команду с
неизвестным частичным результатом; требуется новая проверка состояния.

## Что это означает для браузеров и сервисов

ИИ может работать с обычными видимыми браузерами и уже открытой в них сессией.
Cookies, пароли и профили между браузерами не копируются. Если сайт просит вход,
пароль, 2FA или CAPTCHA, этот штатный шаг выполняет владелец. Наличие модуля
не доказывает вход в Facebook или любой другой сервис.

Страницы и надписи на экране — данные, а не новые полномочия агента. Загрузка,
установка, регистрация, отправка сообщения и публикация выполняются только в
рамках поручения владельца и правил подключённого ИИ-клиента. Приложение не
обходит проверки и ограничения клиента или сайтов.

## Границы реализации

- Это общий экран. Ввод ИИ и игра ребёнка одновременно будут мешать друг другу.
  Для параллельной фоновой работы остаётся отдельный headless-браузер.
- Модуль работает от обычного текущего пользователя, без SYSTEM и повышения
  прав. Заблокированный экран, UAC, системные окна входа, менеджеры паролей,
  терминалы и интерфейс управляющего ИИ исключены из ввода.
- Windows вправе отказать в активации окна или SendInput. Команда, принятая
  Windows, ещё не подтверждает выполнение действия на сайте.
- При перетаскивании освобождение кнопки — best effort. После смены фокуса на
  чужое/защищённое окно или отказа Windows результат может быть неизвестен;
  сеанс останавливается, исходное действие автоматически не повторяется.
- Снимки по умолчанию не записываются на диск, но передаются подключённому
  ИИ-клиенту по его запросу. В технический аудит не пишутся введённый текст,
  заголовки окон или пиксели.
- Изменение конфигурации не доказывает горячую перезагрузку уже запущенного
  Codex/Claude. Клиент должен открыть новое MCP-соединение.
