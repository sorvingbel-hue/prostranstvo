ПРОСТРАНСТВО — КАНАЛЫ УПРАВЛЕНИЯ АГЕНТА
Состояние исходников: 18 ноября 2026 года

Это описание новых компонентов исходников. Последняя упакованная beta остаётся
0.1.12; новый установщик и проверка на чистой Windows ещё не выполнены.

ПРИЛОЖЕНИЯ И ЭКРАН

Каталог включает известные браузеры, Блокнот, Калькулятор, VS Code и Notion.
Проверка наличия и подготовка плана ничего не запускают. Оконный запуск требует
отдельно согласованного использования экрана. Успешный запуск процесса сам по
себе не подтверждает управление приложением или вход в аккаунт.

В «Уроках» родитель с PIN может выбрать Edge, Chrome, Яндекс, VS Code и Notion
для фоновой работы. Их проверенные исполняемые файлы исключаются из обычного
закрытия Study; окна периодически сворачиваются, процессы продолжают работу.
Пустой список ничего не разрешает. Восстановленное окно может оставаться видно
до следующей проверки. На общей учётной записи сворачивание не обеспечивает
разделение доступа: для устойчивых детских ограничений нужна отдельная обычная
детская учётная запись Windows.

ОТДЕЛЬНЫЙ БРАУЗЕР БЕЗ ОКОН

Headless gateway использует собственный профиль Edge. Он умеет открывать
разрешённую HTTPS-страницу, читать её заголовок и текст, нажимать точный элемент,
заполнять разрешённое поле и закрывать только свой браузер. Текущий список
доменов ограничен example.com и Facebook. Действия с последствиями требуют
отдельного поручения пользователя; текст страницы не даёт такого разрешения.

Реальная проверка gateway прочитала заголовок и текст example.com без
видимого окна и ввода с рабочего стола. Работа при устойчивой блокировке Windows
и новый вход Facebook через этот профиль отдельно не подтверждены.
Открытая сессия обычного браузера не переносится; импорт cookies и заполнение
паролей этим каналом не поддерживаются. Node.js и Playwright Core — внешние
необязательные зависимости, в текущий установщик они не входят.

Для ручного входа подготовлены кнопки в «Подключения». Они требуют PIN родителя
и отдельного подтверждения экранного окна. Пока Study активен, окно входа
не запускается. Сейчас к авторизации ещё не приступали.

Ручной вход и фоновые команды используют один и тот же выделенный профиль.
Перед входом нужно закрыть owned context через его контроллер, затем открыть
подготовленное окно и самостоятельно войти на Facebook. Пароль и 2FA вводятся
пользователем. Закрыв именно это окно, подтвердите завершение. Следующее
подключение помощника должно проверить настоящий вход и нужный аккаунт.

Общий lock исключает одновременное владение профилем обновлёнными gateway.
Маркер ручного входа сохраняется на диске и блокирует фоновые команды до
явного завершения; старое подтверждение не может очистить новую сессию.
Старые MCP-процессы нужно переподключить: они не подхватывают этот код по факту
его установки. Ошибка закрытия не считается освобождением профиля. При занятости
профиля приложение не удаляет Chromium Singleton-файлы и не завершает чужие
браузеры. Вход в обычном пользовательском браузере не переносится автоматически.

БЛОКИРОВКА, ПЕРЕЗАГРУЗКА И ВЫКЛЮЧЕНИЕ

lock_computer запрашивает блокировку Windows по явному поручению владельца.
Приложения продолжают работу; успешный вызов отдельно не доказывает завершение
блокировки. Разблокировать сеанс можно обычными учётными данными Windows.
Блокировка и разблокировка не завершают Study и не отменяют его срок.

MCP power_status читает состояние, prepare_power_action только готовит
предложение. Запуск перезагрузки или выключения выполняется во вкладке
«Питание» после подтверждения и PIN родителя. По умолчанию локальный отсчёт
составляет 60 секунд; до отправки Windows запрос можно отменить по его ID.
Документы и игры нужно сохранить заранее. Принудительное закрытие не
запрашивается: после отсчёта используется /r либо /s с /t 0, без /f.

После отправки отмена локального запроса уже не отменяет действие Windows.
Статус dispatched означает принятие команды, а не подтверждённую перезагрузку.
После сбоя возможен uncertain без автоматического повторения. Автозапуск
старого запроса при входе в Windows не регистрируется. Реальные выключение
и перезагрузка при разработке этих компонентов не выполнялись.
