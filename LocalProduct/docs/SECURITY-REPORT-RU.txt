Локальный отчёт безопасности: ограниченное наблюдение

Этот отчёт НЕ является заключением о взломе, отсутствия заражения или полной
защищённости. Он нужен родителю и подключённому ИИ как один небольшой источник
фактов с датой, источниками и явными пробелами. Ничего не исправляет автоматически.

API Python (src/security_report.py):
    store = SecurityReport()
    report = store.collect()
    report = store.latest()                 # None, если отчёта ещё нет
    packet = store.for_ai(report["report_id"])

SecurityReport(root=None, providers=None) ничего не создаёт при конструировании.
latest() и for_ai() только читают уже сохранённый отчёт; они не запускают сбор.
collect() запускает один фиксированный локальный read-only snapshot, проверяет
разрешённые поля и атомарно сохраняет только latest.json под report.lock.
По умолчанию это текущий профиль:
    %LOCALAPPDATA%\ProstranstvoLocalBeta\data\security-report
Установленная копия на D: не используется. root нужен для изолированных тестов;
интерфейс продукта и MCP не должны принимать произвольный путь от ИИ/пользователя.
providers для тестов: {"snapshot": callable, "now": callable}. snapshot возвращает
словарь групп с {"error": null|фиксированный_код, "data": {поля: значения}};
now возвращает datetime с часовым поясом. Произвольные команды не принимаются.

Схема JSON версии 1 (до 48 КиБ):
    schema_version: 1
    report_id: 32 строчные шестнадцатеричные цифры
    collected_utc: YYYY-MM-DDTHH:MM:SSZ
    assessment: "not_a_compromise_verdict"
    evidence: фиксированные группы и поля ниже
Каждое поле evidence — строго {"value": scalar|null, "observed_utc": UTC,
"source": фиксированный_id, "unknown_reason": null|фиксированный_код}.
Дата observed_utc — завершение наблюдения, а не дата последнего обновления/скана.
Для неизвестного значения value всегда null, причина обязательна. Неизвестное
никогда не подменяется значением «включено», нулём угроз или «всё хорошо».
latest() заново проверяет схему, размер, типы и отсутствие лишних полей.
for_ai(report_id) отклоняет подменённый/устаревший идентификатор. В packet входят
тот же report, статические инструкции, freshness {age_seconds, stale} и false
execution_available/network_available. Порог свежести — 24 часа; дата из будущего
считается устаревшей/неопределённой. Свежесть не является оценкой защищённости.

Что действительно наблюдается:
- windows: product (семейство windows/windows_10/windows_11/windows_server),
  release, build, revision из локального реестра. Windows 11 определяется по
  номеру сборки, поскольку ProductName может сохранять старое название Windows 10.
- updates: latest_kb_id и latest_kb_installed_date от Get-HotFix. Это последняя
  видимая установленная KB с датой. Get-HotFix не охватывает все виды обновлений;
  это НЕ проверка наличия всех актуальных обновлений или поддержки версии.
- defender: antivirus_enabled, realtime_enabled, signatures_version,
  signatures_updated_utc, quick_scan_end_utc, full_scan_end_utc,
  quick_scan_overdue, full_scan_overdue от Get-MpComputerStatus.
  Дата/флаг скана — сведения Defender, а не независимо проверенный итог скана.
  Отсутствующая дата полного скана остаётся неизвестной.
- threats: только active_threat_count (IsActive=true от Get-MpThreat), без имён,
  путей, содержимого и истории угроз. Ноль не доказывает отсутствие заражения.
- firewall: domain_enabled/private_enabled/public_enabled от активных профилей
  Get-NetFirewallProfile. Это не аудит отдельных правил или сетевого трафика.
- encryption: system_volume_protection (on/off), system_volume_encryption
  (fully_encrypted/fully_decrypted/encryption_in_progress/decryption_in_progress/
  encryption_paused/decryption_paused). Два фиксированных локальных запроса к
  Win32_EncryptableVolume: GetProtectionStatus и GetConversionStatus.
  Никакие recovery keys, key protectors или их свойства не запрашиваются.
- backup: legacy_windows_backup_configuration_seen — только наличие ключа
  HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\WindowsBackup\ScheduleParams.
  Это частичный признак старой конфигурации, даже если ключ пуст или устарел.
  Его отсутствие не исключает другие средства резервирования. Адреса, каталоги,
  выбранные файлы, содержимое копий не читаются. Надёжность не выводится.
- backup_assurance.restore_tested: всегда null/not_tested. Наличие настройки
  не доказывает успешную копию или успешную проверку восстановления.
- permissions.agent_permissions_coverage и extension_permissions_coverage:
  всегда null/not_collected. Надёжного полного источника разрешений всех
  агентов/браузерных расширений нет; расширения и профили браузера не сканируются.

Ограничения исполнения:
Системный PowerShell находится через GetSystemDirectoryW, запускается напрямую
без shell, профиля, интерактива и видимого окна. Только фиксированный встроенный
скрипт. Рабочая папка — System32; PSModulePath содержит только системные Modules
этого PowerShell и повторно задаётся из PSHOME до первого командлета. Пользовательские
папки модулей и текущая рабочая папка приложения не участвуют в поиске модулей.
stdout ограничен 64 КиБ; PeekNamedPipe проверяет доступные байты перед каждым чтением.
Нет фонового потока с блокирующим read()/close(). Общий срок чтения и ожидания —
18 секунд, в том числе если дочерний процесс вышел, а унаследованный pipe остался
открыт. При превышении лимита завершается только собственный дочерний процесс сбора;
ожидание его завершения при уборке ограничено ещё 1 секундой. stderr отбрасывается.
Отказ доступа/недоступный API/ошибка/таймаут дают фиксированный код неизвестности;
сырые исключения и логи в отчёт не попадают. Нет сетевых запросов, удалённого
управления, UAC, админ-запуска, антивирусного скана, ремонта, удаления, изменения
служб/настроек безопасности, BIOS или перезапуска. Исходный статус не меняется.

Приватность и хранение:
Отчёт не содержит hostname, аккаунт/SID, пользовательские пути, инвентарь файлов,
историю браузера, сообщения, снимки экрана, лицензии, серийные номера, токены,
ключи шифрования и сырые исключения/логи. Только фиксированные поля и скаляры.
Неизвестные/лишние входные поля отбрасываются, произвольный текст не принимается.
Ссылки/junction/hardlink для отчёта/блокировки отвергаются, запись — временный файл,
fsync и os.replace под локальной исключающей блокировкой. Хранится один последний
отчёт, поэтому объём не растёт. Это не защита от другого процесса с теми же полными
правами пользователя, который намеренно меняет файлы в момент проверки.
Никакой автоматической отправки или публикации нет. Передача подключённому ИИ
использует только проверенный packet и отдельное явное действие пользователя.
