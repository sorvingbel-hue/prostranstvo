ОЧИСТКА КЭШЕЙ · LOCAL BETA

Компьютер → Очистка кэшей. Выберите категории и сначала нажмите анализ.
Панель показывает конкретный план: файлы, количество и логический объём.
Очистка по плану требует подтверждения списка и PIN родителя.

Первая версия поддерживает только три восстанавливаемых shader cache
текущего Windows-пользователя: NVIDIA DirectX, NVIDIA OpenGL и Windows
Direct3D. По умолчанию рассматриваются файлы старше7 дней. Содержимое
этих кэшей будет создано заново; первый запуск игры может замедлиться.
Конструктор панели и открытие программы ничего не удаляют.

Удаление выбранных кэш-файлов постоянное: это не перемещение в корзину.
Перемещение в корзину само по себе не освобождает место на том же диске.
Перед каждым удалением проверяются файловая идентичность, размер/время,
атрибуты, ссылки и занятость. Родительские каталоги удерживаются открытыми,
leaf не проходит через reparse; изменившиеся, занятые, read-only и неизвестные
файлы пропускаются. Папки не удаляются, атрибуты не сбрасываются.

План действует30 минут и ограничен5000 записями/4ГиБ. Квитанция сохраняется
наC до действия и после каждого файла. Неоднозначный результат после сбоя
не считается подтверждённым удалением и не повторяется автоматически.
Логические байты и наблюдаемое изменение свободного места показаны отдельно.

Никакого общего DELETE-права для всех путей, shell или SYSTEM-обхода
через эту панель нет. Функция не затрагивает Windows Temp, Windows Update,
историю/пароли браузеров, загрузки игр, проекты, документы и сохранения.
Предыдущие отказы исполнителя не обходятся: такой отказ не является
ошибкой Windows ACL, которую надо снять повышением прав приложения.

Это родительская проверка интерфейса. Прямой код того же Windows-пользователя
не изолируется PIN-окном; отдельный MCP-инструмент удаления не добавлен.
