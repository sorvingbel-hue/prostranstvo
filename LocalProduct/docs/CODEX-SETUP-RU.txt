ПРОСТРАНСТВО · ПОДКЛЮЧЕНИЕ СОБСТВЕННОГО CODEX

Обычное приложение работает локально без аккаунта ИИ. MCP — отдельный
локальный канал, через который совместимый клиент ИИ запрашивает заранее
определённые инструменты. Он не даёт root/SYSTEM и не переносит чужой
аккаунт, чаты, лимиты или подписку. Здесь нет облачного MCP-сервера.

ПЕРЕД ПОДКЛЮЧЕНИЕМ

1. Установите доверенную Local Beta по START-HERE-RU.txt.
2. Установите официальный клиент Codex и войдите в свой аккаунт обычным
   способом. Условия доступа и расход запросов определяет ваш тариф.
   Не отправляйте пароли или токены разработчику программы.
3. Откройте Пространство Local Beta. Оставляйте основное окно открытым,
   если хотите выполнять задания очереди. Для первого теста используйте
   несколько ненужных копий файлов в «Документах» или «Загрузках».

ПОДКЛЮЧЕНИЕ ЧЕРЕЗ CODEX CLI

Если команда codex доступна в Windows PowerShell, выполните:

$bridge = Join-Path $env:LOCALAPPDATA 'Programs\ProstranstvoLocalBeta\app\ProstranstvoCore.exe'
Test-Path -LiteralPath $bridge
codex mcp add prostranstvo-local -- $bridge mcp
codex mcp list

Test-Path должен вернуть True. Команда add добавляет только именованную
локальную MCP-запись. Она не устанавливает автозапуск Windows. Затем
обновите соединения/перезапустите клиент или откройте новую сессию Codex.
В клиенте, поддерживающем /mcp, проверьте соединение этой командой.

Если используется portable-архив, замените значение $bridge на полный
путь к ProstranstvoCore.exe именно в своей распакованной папке. Не меняйте
путь к своей старой личной версии и не подставляйте чужое имя Windows.

В клиенте с ручными настройками local stdio MCP укажите:
Название: prostranstvo-local
Исполняемый файл: полный путь к установленному ProstranstvoCore.exe
Аргументы: mcp
Транспорт: stdio

Не заменяйте config.toml целиком, не копируйте конфигурацию разработчика
и не включайте обход подтверждений. Если клиент допускает только удалённые
HTTP MCP-серверы, эта локальная stdio-версия напрямую к нему не подключается.
Обычный чат ChatGPT в браузере не получает доступ к ПК из одного текста
с командой. Голосовое управление через ChatGPT отдельно не реализовано.

ПРОВЕРКА В ЧАТЕ CODEX

Можно вставить следующий запрос:

«Подключён локальный MCP prostranstvo-local. Сначала вызови только
computer_status и list_jobs. Покажи найденные разрешённые папки и состояние
очереди. Ничего пока не переноси, не подключай внешние аккаунты и не читай
историю/снимки. Затем по моему выбору подготовь обследование небольшой
тестовой папки. Изменения файлов выполняй только по проверяемому плану
с подтверждением в окне Пространства Local Beta.»

Текущие инструменты: computer_status, catalog_search, list_jobs,
queue_inventory, queue_duplicates, prepare_transfer, prepare_undo.
Инструмента произвольного shell, управления SYSTEM, автоматического
чтения всех дисков или отправки сообщений в Telegram в этом MCP нет.
Подготовленный перенос исполняется только после подтверждения в GUI.

ДАННЫЕ И РАСХОДЫ

Сам local stdio канал идёт внутри компьютера. Но запрошенный результат
инструмента становится частью разговора подключённого клиента: он может
передаваться провайдеру ИИ согласно настройкам вашего аккаунта. В него
могут входить имена файлов, пути, описание плана и результаты поиска.
Локальное хранение приложения не делает облачную модель офлайн-моделью.

Не указывайте личные файлы и содержимое, которые не хотите передавать
провайдеру. Никакой ключ OpenAI не встроен. Приложение не обещает бесплатных
или неограниченных обращений к ИИ. Для проверки локальной очереди модель
вообще не нужна — используйте интерфейс.

ОТКЛЮЧЕНИЕ И ПЕРЕНОС НА ДРУГОЙ ПК

В настройках Codex отключите или удалите только запись prostranstvo-local.
Это не удаляет данные приложения. Перед обновлением/удалением beta
закройте её MCP-процесс через клиент, а также окна и видимые агенты.
На другом компьютере устанавливается чистый пакет, выполняется свой вход
в Codex и создаётся новая запись с путём на том компьютере. Получатель
не подключается автоматически к аккаунту разработчика или этому чату.

ЕСЛИ КОМАНДА НЕ РАБОТАЕТ

Проверьте Test-Path, распаковку всей папки _internal и команду codex --help.
Если codex не найден, настройка CLI ещё не завершена; попросите собственный
Codex помочь установить официальный клиент. Не скачивайте случайные
«активаторы», не отключайте защиту Windows и не вставляйте чужие токены.
Текст ошибки передавайте без секретов и личных путей, если они не нужны.

Для другой совместимой ИИ-программы нужен её клиент с local stdio MCP.
Удалённый доступ, публичный облачный коннектор, регистрация приложения
в каталоге ChatGPT и общий сервер пользователей в эту beta не входят.
