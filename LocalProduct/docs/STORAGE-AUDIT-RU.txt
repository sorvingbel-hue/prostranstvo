Анализ места на C и D

storage_audit.py — явно запускаемый локальный анализатор метаданных.
Пример из каталога LocalProduct:
python -B src/storage_audit.py --root C:/ --root D:/ --output C:/StorageAudit

Запуск из чата возможен через локального помощника; отдельная кнопка GUI
и отдельный MCP-инструмент в этой версии не добавлены. На Windows текущая
версия принимает локальные пути на C/D и сохраняет отчёт на C. Сканирование
не включается автоматически при импорте или открытии приложения.

CLI снижает приоритет только своего процесса. Содержимое файлов не читается,
хеширование, удаление, перенос и остановка приложений не выполняются.
Не создаётся второй постоянный каталог файлов: сохраняются report.json и
progress.json. Каталог отчёта исключён из обхода. Это дополнение к существующему
File Atlas, не замена его авторитетного индекса и правил переноса.

Проверяемые ссылки, junction и offline/Recall placeholders исключаются.
Настроенные и стандартные корни OneDrive/iCloud Photos пропускаются отдельно:
Windows может скрывать облачные reparse-флаги от некоторых процессов. Для
других провайдеров или перенесённых корней с такими флагами универсальной
гарантии нет. Ошибки доступа фиксируются; traversal_finished означает завершение доступного обхода,
а не видимость всех данных. Подсчёт логический: это не физически занятые или
гарантированно освобождаемые байты. Hardlinks учитываются по свежим stat/ID;
неизвестные идентификаторы отражаются отдельной границей неопределённости.

В отчёте до 200 крупнейших файлов, категории по расширению и агрегаты папок
до трёх уровней относительно каждого явно заданного корня. Ограничение вывода
не обрывает обход. Для разбора глубокого каталога проектов можно отдельно
указать его корнем. По дате изменения или расширению нельзя заключить, что
файл не нужен. Папки игр, документы, проекты и видео сами не удаляются.

Отчёты содержат личные локальные пути. Их нельзя автоматически публиковать
на GitHub или отправлять внешнему сервису. Источники приложения и тесты можно
передавать отдельно от пользовательских отчётов.
